# NATCO Merchant AI — نسخة مساعد الذكاء الاصطناعي الحقيقي

## ما الذي يعمل؟
- شاشة عربية RTL بتصميم احترافي داكن/أزرق.
- محادثة فعلية مع نموذج AI من خلال خادم وسيط آمن.
- سجل المحادثة ضمن الجلسة، اقتراحات أسئلة، مؤشر انتظار، رسائل أخطاء صريحة، وزر إعادة المحاولة.
- لا توجد ردود AI وهمية أو إجابات احتياطية مكتوبة مسبقًا. عند انقطاع الاتصال أو غياب المفتاح يظهر خطأ واضح.
- بقية وظائف المتجر (الكتالوج الحقيقي، الأسعار، المخزون، الطلبات، الدفع) ليست مفعّلة في هذه النسخة، ولا يدّعي المساعد أنه متصل بأنظمة NATCO.

## مكونات المشروع
- `lib/main.dart`: تطبيق Flutter.
- `server/server.js`: خادم Node.js يرسل الرسائل إلى OpenAI Responses API ويحفظ المفتاح على الخادم فقط.
- `server/.env.example`: أسماء متغيرات البيئة المطلوبة.
- `codemagic.yaml`: إعداد بناء APK.

## إعداد خادم AI الحقيقي
1. انشر مجلد `server` على خادم يدعم Node.js 20 أو أحدث (مثل خدمة استضافة Node). يجب أن يكون للخادم عنوان HTTPS عام.
2. أضف متغير البيئة `OPENAI_API_KEY` في لوحة استضافة الخادم. لا تضع المفتاح في تطبيق Flutter أو GitHub.
3. أضف `OPENAI_MODEL` بالقيمة `gpt-4.1-mini` أو نموذجًا متاحًا لحسابك.
4. شغّل `npm start` من مجلد `server`.
5. اختبر `https://YOUR-SERVER/health`؛ يجب أن يعيد `{"ok":true,"service":"natco-merchant-ai"}`.
6. أضف متغير `AI_API_BASE_URL` إلى Codemagic بقيمة عنوان الخادم HTTPS دون `/api/chat`، مثل `https://your-service.example.com`.
7. ابنِ APK من Codemagic. أمر البناء يمرر العنوان إلى Flutter باستخدام `--dart-define`.

## تشغيل محلي
- شغّل الخادم بعد ضبط `OPENAI_API_KEY` في البيئة.
- على محاكي Android، العنوان الافتراضي `http://10.0.2.2:3000` يشير إلى جهاز التطوير.
- على هاتف فعلي، استخدم عنوان IP المحلي لجهاز التطوير أثناء الاختبار، أو الأفضل عنوان HTTPS منشور.
- لا تستخدم HTTP غير المشفر في إصدار إنتاجي. Android قد يمنع HTTP بحسب إعدادات المنصة.

## ملاحظات مهمة
- استخدام OpenAI API يحتاج حسابًا ومفتاحًا صالحًا وفوترة/رصيدًا متاحًا؛ المفتاح لا يُضمّن في هذا الملف، لذلك لن يعمل الاتصال الفعلي حتى تضع مفتاحك في الخادم وتنشره.
- الخادم يتضمن معالجة أخطاء وحدًا لحجم الرسالة، لكنه نموذج بداية. قبل الإطلاق العام أضف مصادقة، تحديد معدل الطلبات لكل مستخدم، سجلات مراقبة آمنة، وسياسة خصوصية. لا تترك `ALLOWED_ORIGIN=*` إذا كان الوصول محصورًا على نطاق معروف.
- لا يحتوي هذا الإصدار على تكامل رسمي مع NATCO أو OneCash أو Mahfadhi.
